# ScreenMarker

Marcador de tela para Windows: desenhe setas, formas, texto e marca-texto por cima de qualquer programa.

## Uso

- `Ctrl+Alt+D` liga/desliga a marcação
- `Ctrl+Alt+F` marca com a tela congelada
- `Ctrl+Alt+O` abre as configurações (atalhos, cores, barra horizontal/vertical)

## Rodar

```powershell
python -m pip install -r requirements.txt
python run.py
```

## Compilar e instalar

```powershell
.\build.ps1 -Zip
.\install.ps1
```
